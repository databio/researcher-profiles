# Expertise Profile: Jane A. Doe

## Methods Championed

### Example Region Set Analysis
Doe has developed computational methods for working with collections of example
regions. This includes ExampleOverlap for enrichment analysis of region sets
against reference collections [doe2016example] and methods for constructing
consensus region universes using coverage cutoffs and probabilistic models
[doe2019methods].

### Reproducible Pipeline Development
A core expertise is reproducible workflow design. Doe's group contributed a
toolkit for portable example workflows [roe2018toolkit] and analysis pipelines
that emphasize provenance and restartability.

### Sample Metadata Standardization
Doe leads development of the Portable Example Projects (PEP) ecosystem for sample
metadata interoperability, surveyed against the broader standards landscape
[poe2022survey] and extended toward AI-ready provenance metadata
[doe2023framework].

### Vector Representations of Example Regions
Recent work focuses on embedding example region sets into vector spaces for
machine learning applications [doe2021widgets], including transformer-based
foundation models for region sequences [doe2025recent] and large synthetic
accessibility atlases [doe2024atlas].

## Recurring Critiques and Positions

### Metadata is the Bottleneck
A consistent theme is that poor metadata quality impedes data reuse; sharing
metadata is as important as sharing data itself [poe2022survey, doe2023framework].

### Naive Union Consensus is Problematic
Using naive union operations to build consensus regions loses boundary
information; principled alternatives are preferred [doe2019methods].

## Career Trajectory

### Recent Work
The recent phase emphasizes machine-learning infrastructure and standards for
