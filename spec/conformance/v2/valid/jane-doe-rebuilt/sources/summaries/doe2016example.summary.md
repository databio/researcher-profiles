Doe developed ExampleOverlap, a package for enrichment analysis of example region
sets against curated reference collections. The tool addresses a limitation of
gene-set methods: their inability to handle coordinate-based data from
high-throughput experiments. ExampleOverlap tests whether a query set of example
regions significantly overlaps reference sets, ranking associations by combining
p-value, effect size, and overlap count. It ships with a core reference database
assembled from public synthetic resources.
